# Тестовые режимы Pokereza Poker

Этот файл — краткая памятка по временным тестовым переключателям игры. Тестовые режимы управляются из `js/main.js` и по умолчанию должны быть выключены.

## Где находятся переключатели

В начале `js/main.js`, сразу после строки с версией игры:

```js
const GAME_VERSION='v0.5.10 alpha';

// ВРЕМЕННЫЕ ТЕСТОВЫЕ РЕЖИМЫ
const TEST_FIRST_HAND_AI_ALL_IN = false;
```

Для включения или выключения режима достаточно изменить `false` на `true` или обратно. Основную логику ИИ и анализ его решений менять не нужно.

## Доступный режим

### Все ИИ идут ALL-IN в первой раздаче

**Переключатель:** `TEST_FIRST_HAND_AI_ALL_IN`

- `true` — когда наступает ход ИИ в первой раздаче (`handNo === 1`), вместо обычного решения ИИ применяется действие `{ t: 'allin' }`.
- `false` — ИИ действует по обычной логике через `decide(...)`.
- Режим действует только на ИИ, не заставляет пользователя идти ALL-IN.
- Начиная со второй раздачи обычная логика ИИ используется независимо от значения переключателя.

**Где применяется:** `js/main.js` → функция `scheduleAI()` → строка выбора `action` (сейчас около строки 1411):

```js
const call=Math.max(0,currentBet-players[i].bet),action=TEST_FIRST_HAND_AI_ALL_IN && handNo === 1?{ t:'allin'}:decide(players[i],call,board,currentBet,bb);
```

Менять эту строку для обычного включения/выключения теста не требуется. Переключайте только `TEST_FIRST_HAND_AI_ALL_IN` в начале файла.

## Как пользоваться

1. Перед тестированием откройте `js/main.js`.
2. Включите нужный режим, установив его переключатель в `true`.
3. Запустите игру заново и проведите тест.
4. После проверки верните переключатель в `false`, чтобы тестовый сценарий не попал в обычную сборку.

Текущий статус при создании этой памятки: `TEST_FIRST_HAND_AI_ALL_IN = false` — режим выключен.

## Как добавлять новые тестовые режимы

Новые переключатели размещать рядом с `TEST_FIRST_HAND_AI_ALL_IN` в начале `js/main.js`, чтобы все временные режимы находились в одном месте.

Рекомендуемый формат:

```js
// ВРЕМЕННЫЕ ТЕСТОВЫЕ РЕЖИМЫ
const TEST_FIRST_HAND_AI_ALL_IN = false;
const TEST_NEW_SCENARIO = false;
```

Для каждого нового переключателя в этом файле добавлять отдельный подраздел с четырьмя пунктами:

- название и назначение режима;
- имя переключателя и значения `true` / `false`;
- точное место применения в коде (файл, функция и условие);
- какие действия изменяются и какие части игры не затрагиваются.

Тестовые условия должны быть изолированными: не менять `js/ai.js`, `js/ai-analysis.js` и основную игровую логику, если задача теста этого прямо не требует. Неиспользуемые тестовые режимы держать выключенными (`false`).
