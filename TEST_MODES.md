

# Тестовые режимы Pokereza Poker

Временные тестовые переключатели находятся в начале `js/main.js`, сразу после строки с версией игры. По умолчанию все режимы должны быть выключены, кроме таймера хода, который включён в обычном режиме.

## Переключатели

```js
// ВРЕМЕННЫЕ ТЕСТОВЫЕ РЕЖИМЫ
const TEST_FIRST_HAND_AI_ALL_IN = false;
const TEST_MANUAL_NEXT_HAND = false;
const TEST_ALL_HANDS_AI_ALL_IN = false;
const TEST_ACTION_CLOCK_ENABLED = true;
```

## Доступные режимы

### 1. Все ИИ идут ALL-IN в первой раздаче

**Переключатель:** `TEST_FIRST_HAND_AI_ALL_IN`

- `true` — все ИИ идут ALL-IN в первой раздаче.
- `false` — ИИ используют обычную логику принятия решений.

**Где применяется:** `js/main.js` → `scheduleAI()`.

### 2. Ручной переход к следующей раздаче

**Переключатель:** `TEST_MANUAL_NEXT_HAND`

- `true` — автоматический переход отключён, после завершения раздачи появляется кнопка «РАЗДАЧА».
- `false` — после завершения основных анимаций игра ждёт 3 секунды и автоматически начинает следующую раздачу.
- Режим работает и после вылета пользователя: ИИ продолжают турнир до определения чемпиона.

**Где применяется:**
- `js/main.js` → `finish()` — автоматический переход и ожидание анимаций.
- `js/main.js` → `newHand()` — запуск следующей раздачи независимо от вылета пользователя.
- `js/render.js` → отображение кнопки «РАЗДАЧА».

### 3. ALL-IN ИИ на каждой раздаче

**Переключатель:** `TEST_ALL_HANDS_AI_ALL_IN`

- `true` — все ИИ идут ALL-IN на каждой раздаче.
- `false` — действует обычная логика ИИ или отдельный режим первой раздачи.

**Где применяется:** `js/main.js` → `scheduleAI()`.

### 4. Таймер хода

**Переключатель:** `TEST_ACTION_CLOCK_ENABLED`

- `true` — таймер хода включён, по истечении времени пользователь автоматически сбрасывает карты.
- `false` — таймер и автоматический фолд отключены.

**Где применяется:** `js/main.js` → `startActionClock()`.

## Как пользоваться

1. Откройте `js/main.js`.
2. Установите нужный переключатель в `true` или `false`.
3. Перезапустите игру и проведите тест.
4. После проверки верните временные режимы в исходные значения.

## Правила добавления тестовых режимов

- Все переключатели размещать рядом в начале `js/main.js`.
- Для каждого режима описывать назначение, значения `true` / `false` и место применения.
- Тестовые условия изолировать от основной логики игры.
- Неиспользуемые режимы держать выключенными (`false`).
