
# TEST MODES

Тестовые режимы для быстрой проверки игровой логики, анимаций и поведения ИИ.

Все переключатели находятся в начале файла `js/main.js`, сразу после объявления версии игры.

По умолчанию тестовые режимы выключены. Перед обычной игрой необходимо убедиться, что все тестовые переключатели возвращены в `false` (кроме таймера хода).

## Тестовые переключатели

```js
// Первая раздача: все ИИ идут ва-банк.
const TEST_FIRST_HAND_AI_ALL_IN = false;

// Ручной запуск следующей раздачи после завершения текущей.
const TEST_MANUAL_NEXT_HAND = false;

// Все ИИ идут ва-банк на каждой раздаче.
const TEST_ALL_HANDS_AI_ALL_IN = false;

// Быстрый переход к шоудауну после раздачи карт и выставления блайндов.
const TEST_FAST_SHOWDOWN = false;

// Таймер хода.
const TEST_ACTION_CLOCK_ENABLED = true;
```

---

### 1. Все ИИ идут ва-банк на первой раздаче

**Переключатель:** `TEST_FIRST_HAND_AI_ALL_IN`

- `true` — на первой раздаче все ИИ автоматически идут ва-банк.
- `false` — ИИ действует по обычной игровой логике.

**Назначение:** проверка сценария олл-ина, определения победителя и завершения первой раздачи.

---

### 2. Ручной запуск следующей раздачи

**Переключатель:** `TEST_MANUAL_NEXT_HAND`

- `true` — после завершения раздачи игра ожидает ручного запуска следующей.
- `false` — следующая раздача запускается автоматически по обычной логике.

**Назначение:** проверка результатов раздачи, отображения комбинаций, анимаций и состояния игрового стола перед началом следующей руки.

---

### 3. Все ИИ идут ва-банк на каждой раздаче

**Переключатель:** `TEST_ALL_HANDS_AI_ALL_IN`

- `true` — все ИИ автоматически идут ва-банк на каждой раздаче.
- `false` — ИИ действует по обычной игровой логике.

**Назначение:** многократная проверка олл-инов, вскрытия карт, определения комбинаций и распределения банка.

---

### 4. Таймер хода

**Переключатель:** `TEST_ACTION_CLOCK_ENABLED`

- `true` — таймер хода включён.
- `false` — таймер хода отключён.

**Назначение:** проверка ограничения времени на принятие игрового решения.

---

### 5. Быстрый переход к шоудауну

**Переключатель:** `TEST_FAST_SHOWDOWN`

- `true` — после раздачи карманных карт и выставления блайндов игра автоматически открывает все пять общих карт и переходит к шоудауну.
- `false` — игра проходит обычную последовательность улиц и ставок.

**Где применяется:** `js/main.js` → `runBlindSequence()` → `runOutBoard()`.

**Назначение:** быстро проверять:
- раздачу карманных карт;
- анимации открытия флопа, тёрна и ривера;
- вскрытие карт ИИ;
- отображение покерных комбинаций;
- определение победителя;
- завершение раздачи и распределение банка.

**Важно:** режим пропускает этапы ставок, но использует штатную механику открытия общих карт и завершения раздачи. Основная логика определения комбинаций и победителя не заменяется тестовой.

---

## Правила использования

1. Тестовые переключатели включаются только на время проверки.
2. Для обычной игры все тестовые режимы должны быть выключены.
3. Не включать одновременно несколько режимов без необходимости.
4. После завершения тестирования возвращать изменённые переключатели в исходное состояние.
5. Новые тестовые режимы добавлять изолированно, не изменяя основную игровую логику без необходимости.
6. При добавлении нового переключателя обязательно описывать его назначение, поведение и способ включения в этом документе.
