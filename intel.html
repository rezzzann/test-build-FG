ПОСЛЕДНИЕ ОБНОВЛЕНИЯ
v0.5.6 alphaОбновление
Улучшена настройка ставок. В классическом режиме диапазон ползунка составляет 20–1000 PP. В режиме HIGH ROLLER сохранён диапазон 200–10000 PP, шаг изменения ставки — 10 PP. Также уточнены сведения о последних изменениях игры.
v0.5.2 alphaУлучшение
Обновлён список последних обновлений. Теперь можно хранить до 20 последних записей, сначала отображаются пять, остальные открываются одной кнопкой.
v0.5.1 alpha · Build 003Улучшение
Версия и Build отображаются на главном экране. Номер сборки включён в строку версии игры. В информации об игре также показывается актуальная версия с номером Build.
v0.5.1 alpha · Build 002Улучшение
Уточнены названия обновлений. Для сборок Build используются категории «Новое», «Улучшение» и «Исправление» в зависимости от изменений. Мелкие версии без Build обозначаются как «Обновление», а крупные версии получают особое оформление.
v0.5.1 alpha · Build 002Улучшение
Временные подписи действий стали компактнее. Над иконками игроков показывается только название действия — без суммы ставки после слов «РЕЙЗ», «СТАВКА», «М. БЛАЙНД» и «Б. БЛАЙНД».
v0.5.1 alphaОбновление
Улучшено отображение интерфейса. Уточнено отображение номера раздачи. Добавлено напоминание о возможности сообщить о недоработках и багах через меню игры после пятой завершённой раздачи.
v0.5.0 alphaКрупное обновление
Новый этап Pokereza Tournament. Обновлён главный экран и меню выхода: можно вернуться к текущей игре или начать заново. Улучшено отображение ставок и сохранение состояния раздачи при выходе.
v0.4.1Обновление
Уточнено поведение меню и возврата к игре. Исправлены детали интерфейса, связанные с отображением ставок и продолжением раздачи.
v0.4.0 alpha · Build 023Исправление
Исправлены перезапуск игры, сохранение ставок при выходе и продолжении, увеличена кнопка выхода.
v0.4.0 alpha · Build 022Новое
Добавлена кнопка «ВЫХОД» в игровом интерфейсе. Меню позволяет продолжить текущую игру или начать заново со сбросом стека.
v0.4.0 alpha · Build 021Улучшение
Описание проблемы стало необязательным. Удалено поле действий перед ошибкой. Добавлена подсказка об обязательном выборе вариантов.
v0.4.0 alpha · Build 020Улучшение
Форма сообщения об ошибке получила категории проблем и уточняющие вопросы.
v0.4.0 alpha · Build 019Новое
Добавлена отправка отчётов об ошибках автору через Telegram.
v0.4.0 alpha · Build 018Улучшение
Добавлены плавные переходы между меню и информационными окнами.
